#  Online Banking Application (Backend)

A robust, modular backend application built with **Java Spring Boot** to simulate core functionalities of an online banking system. The project covers customer management, account handling, transaction processing, and email notifications, built on clean code principles and scalable architecture.

---

##  Features

-  **Customer Registration & Login** (future Spring Security planned)
-  **Account Management**: Create and manage savings/checking accounts
-  **Money Transfer**: Transfer funds between accounts securely
-  **Transaction History**: View recent transactions
-  **Email Notification**: Sends confirmation emails on key actions
-  **REST APIs**: Structured and modular REST API endpoints
-  **Database Integration**: MySQL with JPA/Hibernate
-  **Logging**: Add logging soon using SLF4J/Logback
